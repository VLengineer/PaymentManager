# Полное приложение на чистом HTML/CSS/JS (Vanilla JS)

Это полноценное Single Page Application (SPA) для системы "Платежный календарь (БДДС)", написанное на чистом JavaScript без использования фреймворков.

## 📁 Структура файлов

```
vanilla-app/
├── index.html      # Главная HTML-страница
├── styles.css      # Все стили приложения
├── app.js          # Логика приложения
└── README.md       # Эта документация
```

## 🚀 Как запустить

### 1. Запустите бэкенд

```bash
cd /workspace/app/backend
source venv/bin/activate  # если используется виртуальное окружение
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 2. Откройте приложение

Просто откройте файл `index.html` в браузере или используйте локальный сервер:

```bash
# Вариант 1: Python HTTP server
cd /workspace/app/vanilla-app
python -m http.server 8080

# Вариант 2: Node.js http-server
npx http-server -p 8080
```

Затем откройте в браузере: `http://localhost:8080`

## 🎨 Особенности реализации

### Архитектура
- **SPA (Single Page Application)** - переключение между разделами без перезагрузки страницы
- **Модальные окна** - для форм добавления/редактирования
- **Табличное отображение** - для списков данных
- **Адаптивный дизайн** - работает на мобильных устройствах

### Технические детали
- Чистый JavaScript (ES6+)
- Async/await для работы с API
- Fetch API для HTTP-запросов
- CSS Grid и Flexbox для макета
- CSS анимации для модальных окон
- Локальное состояние приложения (глобальные переменные)

### Стилизация
- Градиентные элементы дизайна
- Цветовые индикаторы статусов
- Иконки emoji для визуальной навигации
- Адаптивная верстка для разных экранов
- Стили для печати

## 🔧 Настройка API

В файле `app.js` указана базовая URL для API:

```javascript
const API_BASE_URL = 'http://localhost:8000/api';
```

Если ваш бэкенд работает на другом порту или хосте, измените эту константу.

## 📝 Примечания

1. **Аутентификация**: В текущей реализации используется упрощенная схема входа. В production-версии необходимо добавить proper authentication через JWT или сессии.

2. **CORS**: Убедитесь, что бэкенд настроен на прием запросов с вашего домена (в main.py уже настроено для localhost:5173 и localhost:3000).

3. **Валидация**: Формы имеют базовую HTML5 валидацию. Для production рекомендуется добавить дополнительную клиентскую валидацию.

4. **Обработка ошибок**: Приложение обрабатывает основные ошибки подключения и отображает сообщения пользователю.
